# maklabs

`maklabs` is my personal development playground for trying out whatever is useful or interesting at the moment.

- Jira: getting, updating, and creating tickets.
- Confluence: reading, updating, and creating docs.
- Directus: migrated experiments from `directusx`.
- Infra: IaC practice with Terraform, Terragrunt, AWS, and possibly cross-provider setups.
